## 三、详细设计

### 3.1 数据结构设计

#### 3.1.1 会话对象

```typescript
interface Session {
  id: string;           // 会话唯一标识 (UUID)
  title: string;        // 会话标题
  messages: Message[];  // 消息列表
  createdAt: number;    // 创建时间戳
  updatedAt: number;   // 更新时间戳
}
```

#### 3.1.2 消息对象

```typescript
interface Message {
  id: string;           // 消息唯一标识
  role: 'user' | 'assistant';
  content: string;      // 消息内容
  loading?: boolean;    // 是否正在加载（流式输出时使用）
}
```

#### 3.1.3 存储结构

```typescript
// localStorage 结构
{
  sessions: Session[];      // 会话列表
  currentSessionId: string; // 当前会话ID
}
```

### 3.3 后端 API 设计

#### 3.3.1 新增接口

| 接口 | 方法 | 描述 |
|------|------|------|
| `/api/sessions` | GET | 获取所有会话列表 |
| `/api/sessions` | POST | 创建新会话 |
| `/api/sessions/:id` | DELETE | 删除会话 |
| `/api/sessions/:id/title` | POST | 生成会话标题 |

#### 3.3.2 聊天接口修改

| 接口 | 方法 | 修改内容 |
|------|------|----------|
| `/chat` | POST | 新增 sessionId 参数，支持会话上下文 |

### 3.4 标题生成策略

#### 3.4.1 生成时机

- 用户发送消息后，AI 回答完成时触发
- 仅在会话第一条消息完成后生成

#### 3.4.2 生成方式

调用 AI 总结对话，生成简短标题：

```
用户：什么是 usecallback 以及它有什么作用
AI：[流式输出完整回答]

→ 调用总结API
→ 输出："usecallback的解释"
```

#### 3.4.3 生成 Prompt

```python
# 标题生成 prompt
请根据用户的问题生成一个简短的会话标题（不超过20字），
只返回标题本身，不要任何解释。
用户问题：{用户的第一条消息}
```
